最近验证基线：0.1.3 当前生产源码已通过 14 项 JVM、Debug/Release Lint、正式签名构建；证书与旧版一致。手机与 API 29 常规套件均返回 OK（24 用例中 5 个发布专用探针按条件跳过，19 个实际执行，包含六个版本真实联网读取）。新增的正向网络传输检查和离线阅读界面检查另行验证，不能冒充已包含在此前整套结果中。

证据：`artifacts/013-phone-reliability-first.log`、`013-checks.log`、`013-final-checks.log`。正式版升级前已通过系统文件选择器导出并复制完整的旧格式备份到 `artifacts/013-official-pre-upgrade.zip`（13,778 字节）；正式《山间来信》位置为第 1 章第 2 / 11 页，见 `013-progress-before.xml`。

手机与 API 29 各通过五个真实进程退出阶段的重启恢复。手机通过 500MiB 备份往返、超限拒绝和取消清理，详见 `artifacts/013-large-backup-benchmark.json`；250ms 采样 PSS 峰值 95,001KiB，不能当作全局内存上限。100 本 × 1,000 章、30 次单次写入测试：旧流程中位数 69,127µs，独立进度 13,178µs；负载分别 90,967 与 118 字节。测试只比较写入，不代表全部书架查询或整机流畅度。

首轮 Android 目录别名引用错误已修复并通过。API 29 初次启动的 System UI 无响应弹窗已记录；快速翻页在主机空闲后完整通过。并行操作测试改用显式完成信号，移除了固定延时带来的测试竞态。8MiB 传输用例的模拟服务端曾同时保留两份数据，超过该镜像 16MiB Java 堆；已释放验证完的上传缓存，保持原数据量和校验标准重跑。
