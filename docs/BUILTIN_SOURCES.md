# 内置经典书源

0.1.1 提供两个来源、四部作品、六个版本入口。搜索在应用内的精选书目索引中完成，支持简体、繁体书名及下表作者名；目录与正文从原站获取。它不是两个站点的完整搜索引擎，也不包含商业连载小说目录。

首次安装或从 0.1.0 升级时补充内置书源，不覆盖已有书源。关闭或删除后，下次启动不会擅自恢复；可以在“书源管理 → 恢复内置经典书源”补回缺失项。关闭状态、改名和分组均会保留。新增初始化状态参与本地备份恢复。

内置适配器只负责指定版本的目录和正文处理；导出中的 `wanjuanProvider` 是万卷扩展，其他阅读器不一定识别。用户导入的常用 Legado JSON 规则继续由原有引擎处理。

维基文库逐章读取 HTML，剔除导航和编辑控件。古登堡首次读取一个版本时下载整部 UTF-8 文本，缓存原始文件 7 天，包含原始制作说明与许可信息；阅读时分章展示、合并硬换行。当前最多两份原文文件，每份网络响应上限 8 MiB；内存只保留最近一份已解析版本。缓存属于应用缓存目录，系统可回收。原文保留版本中的繁简用字，没有自动改写正文。

来源说明与许可以各作品页为准：维基文库站点说明见 https://zh.wikisource.org/wiki/Wikisource:版权信息；Project Gutenberg 使用说明见 https://www.gutenberg.org/policy/license.html 。应用展示来源名称，书源管理保留原站地址，不宣称作品由万卷创作或由站点官方授权推荐。

可用性受网络与原站变更影响。离线阅读请提前缓存章节；本次实际检查范围、版本与日期记录在 [验证记录](TESTING.md)。
