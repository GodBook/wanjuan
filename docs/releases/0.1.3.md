# 万卷 0.1.3

本次更新完善阅读失败反馈、换源后的书签保护、离线备份和下载继续行为，并减少保存阅读进度的开销。

- 备份可选择包含已下载的在线正文，恢复预览明确显示内容范围；恢复后离线章节继续受缓存清理保护。新备份格式仍可读取旧版备份。
- ZIP、WebDAV 传输与哈希校验改用流式处理，导出时检查大小限额；文件备份和 WebDAV 手动备份支持取消，恢复提交阶段会先完成当前操作。
- 阅读失败持续显示具体原因，区分加载、空章节和失败状态，提供重试、目录及返回入口。
- 换源保留已读完、分组、置顶和单书设置。旧书签保留摘录与笔记，版本改变时要求确认对应章节；目录更新按章节身份保留位置。
- 下载暂停后继续沿用原网络策略，跳过已缓存章节。旧版未完成任务可点击继续重建；换源或移出书架时取消关联任务。
- 新增存储管理，按书名和章节显示本地文件、下载、临时缓存及资源占用，分类可展开，文件路径按需查看；支持预览后选择删除，保护当前书籍、全局设置和预设引用的资源。
- 阅读进度独立存储，避免反复编码完整目录；搜索历史按最近使用排序，可清空；修复连续搜索与并行操作的状态反馈，展示自动备份失败与重试信息。

Android 10 及以上，使用原发布签名覆盖安装，保留现有书架和阅读数据。下载 `wanjuan-0.1.3.apk`，或从旧版“设置 → 检查更新”升级。

书源兼容仍为明确子集，内置入口仍为精选经典书目；WebDAV 是快照备份，不是多设备实时同步。备份单文件限制 100MiB、解压总量限制 512MiB；旧版应用不能恢复新格式备份。

设备、性能与恢复验证的实际结果见 [验证记录](https://github.com/GodBook/wanjuan/blob/main/docs/TESTING.md)。
