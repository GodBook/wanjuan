# 万卷 0.1.0

Android 10 及以上的本地优先文字阅读器，无需注册，不内置书源。

- 导入 TXT、文字 EPUB 与基础插图，自动分章、保存阅读位置。
- 导入多个 Legado JSON 书源，聚合搜索、读取目录与正文、手动换源。
- 覆盖 / 滑动 / 无动画 / 滚动阅读；字体、字号、间距、颜色、背景与单书设置。
- 书签、笔记、正文查找、分组书架、分批离线下载与暂停继续。
- 文件备份恢复、加密保存的 WebDAV 配置、每日自动备份。
- GitHub Releases 在线更新，验证 SHA-256、版本、包名和签名后交给系统安装。

下载 `wanjuan-0.1.0.apk` 安装。`update.json` 是应用更新元数据，`SHA256SUMS.txt` 可用于独立校验。

书源兼容为明确子集：不支持复杂登录、动态网页、任意 Java 宿主接口或完整 Legado 扩展。EPUB 不支持 DRM、固定版式或复杂 CSS。完整 V1 设计中的进阶功能与验收差距见仓库设计文档。

后续版本使用同一签名，可直接覆盖升级。应用内入口：设置 → 检查更新。
