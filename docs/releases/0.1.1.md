# 万卷 0.1.1

- 内置中文维基文库和 Project Gutenberg 两个经典书源，提供《红楼梦》《西游记》《三国演义》《儒林外史》的六个版本入口，支持简繁书名和作者搜索。书源可关闭、删除或手动恢复。
- 新增“找一本书”和经典书名快捷入口，键盘可直接发起搜索；统一纸色与墨绿色界面，改善封面排版、深色模式对比、系统栏主题和续读书籍选择。
- 翻页直接绘制前后页，移除每次翻页的整屏位图分配；增加滚动惯性，减少重复进度回调。
- 复用网络连接池，将书架解析、正文整理与背景图片解码移出主线程；缓存字体，避免无关设置触发重新分页。
- 修复新增书源初始化状态的备份恢复，以及古登堡版本的硬换行、卷首制作说明和特殊数字分章。

Android 10 及以上。下载 `wanjuan-0.1.1.apk`，或在旧版“设置 → 检查更新”升级；同签名覆盖安装保留数据。内置书源是明确的经典书目索引，非全站搜索；其他在线小说继续支持自行导入书源。
